# Proyecto Orbix Frontend

Frontend del proyecto Orbix desarrollado con **React + TypeScript + Vite**.

---

## Tecnologías

- React
- TypeScript
- Vite
- Git
- GitHub

---

## Clonar el repositorio

> **Importante:** Antes de clonar el proyecto, realiza un **Fork** del repositorio original a tu cuenta de GitHub.

Clona tu copia del repositorio:

```bash
git clone https://github.com/TU_USUARIO/proyecto_orbix_Frontend.git
```

Ingresa al proyecto:

```bash
cd proyecto_orbix_Frontend/frontend
```

---

## Instalar dependencias

```bash
npm install
```

---

## Ejecutar el proyecto

```bash
npm run dev
```

Luego abre en el navegador:

```text
http://localhost:5173
```

---

## Estructura de ramas

| Rama | Cómo se creó | Propósito |
|------|--------------|-----------|
| `main` | Rama principal del repositorio. | Contiene la versión estable del proyecto. |
| `dev` | Se creó desde `main` con `git checkout -b dev`. | Rama donde se integran las funcionalidades antes de pasar a `main`. |
| `feature/login` | Se creó desde `dev` con `git checkout -b feature/login`. | Desarrollo de la funcionalidad de inicio de sesión. |
